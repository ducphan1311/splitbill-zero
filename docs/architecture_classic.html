SplitBill Zero — System Architecture & Component Interaction Diagram
Standard UML & Subsystem Decomposition: Host Interaction, Edge AI OCR, Collaborative Room Mesh, and Financial Settlement

1. Client Interaction Subsystem
Host Application Flutter 3.x
Manages camera session, receipt ingestion, room creation, and final table settlement monitoring.
Guest Web Client Svelte / PWA
Zero-install mobile web client (<250KB). Loaded via QR scan with zero authentication friction.
Collaborative Dish Board UI Component
Synchronized canvas of line items with real-time peer selection tags and instant subtotal calculation.
Universal Bank Intent Router Mobile OS Intent
Invokes registered banking app schemes on iOS/Android with pre-filled payment details.
Host Settlement Monitor WebSocket Client
Live table dashboard tracking paid vs. pending transfers with real-time peer checkmarks.
2. Edge Ingestion & OCR Subsystem
Frame Extraction Pipeline CameraX / AVFound.
Captures 30fps YUV420 image buffers with hardware auto-focus and illumination normalization.
On-Device Text Recognition ML Kit v2
Neural Latin/Vietnamese text recognition engine running offline on device NPU/CPU.
Spatial 2D Geometric Clustering Algorithm
Groups fragmented text blocks by vertical proximity (|ΔY| ≤ 0.5 * LineHeight) and pairs names with VND prices.
Receipt Normalizer & Tax Allocator Parser Core
Extracts subtotal, VAT (8-10%), and service surcharges into structured BillItem collections.
Sum Discrepancy Validator Integrity Check
Validates sum of parsed items against receipt grand total. Flags discrepancies for host confirmation.
3. Collaborative Mesh Subsystem
WebSocket Realtime Gateway Supabase WS
Low-latency bidirectional Pub/Sub message broker routing room state on topic `room:${roomId}`.
In-Memory Session Store Redis / Edge KV
Transient cache holding table state, line items, and guest claims. Configured with 2-hour TTL auto-purge.
Fair-Split Mathematical Matrix Math Engine
Deterministic split engine: Individual Cost = Private + (Shared / N_guests) + Proportional VAT.
Peer Presence Daemon State Tracker
Monitors connection health, detects disconnects, and maintains authoritative active participant roster.
Payment Event Reconciler Consumer
Consumes incoming settlement webhook notifications and broadcasts `PAID` events to the room.
4. Fintech Settlement Subsystem
EMVCo Tag Synthesizer NAPAS 247
Encodes payload: Tag 00 (Format), Tag 26 (Bank BIN + Acc), Tag 53 (704 VND), Tag 54 (Amount), Tag 62 (Memo).
CRC-16 / CCITT-FALSE Engine Checksum
Calculates standard 16-bit redundancy polynomial 0x1021 ensuring 100% banking scanner compatibility.
Dynamic QR Matrix Generator ISO 18004
Generates crisp vector ISO/IEC 18004 QR codes containing individualized payment data.
Guest Banking Applications 40+ VN Banks
Vietcombank, Techcombank, VPBank NEO, MBBank, Timo, Cake, Viettel Money, and partner apps.
Napas 24/7 Interbank Network Instant Clearing
Facilitates instant real-time settlement directly into Host bank account. Zero escrow, zero fees.
